# 32LDK オンライン（非公式）

ボードゲーム「32LDK」（デザイン：ナラセン／発行：ロクジゾー）を、スマホのブラウザで遊べるようにした非公式ファンメイド版です。ルールは公式説明書に準拠しています。

- 部屋を作ると招待リンク（`https://<あなたのURL>/?room=ABCD`）が出ます。リンクを開いた人はニックネームを入れるだけで参加できます（アカウント不要）
- 3〜6人。ゲーム数（1 / 2 / 人数分）と「連続出しルール」を選べます
- 手札や扉の中身はサーバーだけが持ち、各プレイヤーには自分の手札だけが届きます
- 通信が切れても同じ端末で開き直せば自分の席に戻れます
- 「1台で遊ぶ」モード（スマホを回して遊ぶ）も入っています

## ローカルで動かす

```bash
npm install
npm start
# → http://localhost:3000
```

## Render に公開する

1. GitHub に新しいリポジトリを作り、このフォルダの中身（`node_modules` 以外）をアップロード
2. Render（https://render.com）で **New → Blueprint** を選び、そのリポジトリを指定
   （`render.yaml` を読み込んで無料プランの Web Service が作られます）
   - Blueprint を使わない場合は **New → Web Service** で、Runtime: Node / Build: `npm install` / Start: `npm start` / Instance: Free
3. デプロイ完了後に表示される `https://xxxx.onrender.com` を友だちに共有

### 無料プランの注意
- 15分ほどアクセスがないとサーバーが眠り、次に開いたとき起動に30秒〜1分かかります
- 部屋はサーバーのメモリに保存しているため、再起動・再デプロイすると進行中の部屋は消えます
